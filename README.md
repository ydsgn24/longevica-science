# Longevica Science

Landing page for Longevica Science — React + Vite + TypeScript + Tailwind CSS.

```bash
npm install
npm run dev     # http://localhost:8080
npm run build
```

- All site copy: `src/content.ts`
- Legal pages (Privacy, Cookie, Legal Notice): `src/legal.ts` — values in `[brackets]` are placeholders to fill in
- Sections: `src/components/Sections.tsx`; animations: `src/components/motion.tsx`
- Images: `public/images/`, partner logos: `public/images/partners/`
- The contact form validates on the client and shows "Thank you!"; submissions are not stored yet.
